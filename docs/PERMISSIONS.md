# PERMISSIONS.md

## Required permissions v0.1

- `activeTab`
- `scripting`
- `sidePanel`
- `storage`
- `tabs`

## Optional permissions

- `audioCapture` only for explicit voice dictation fallback.

## Host permissions

- `http://127.0.0.1/*`
- `http://localhost/*`
- `http://*/*`
- `https://*/*`

## Not requested v0.1

- `debugger`
- `nativeMessaging`
- `cookies`
- `history`
- `downloads`
- `bookmarks`
- browser-control permissions

v0.1 is read-only. It does not click, type, submit forms, buy, delete, download, or control pages.
