# ACCEPTANCE-REPORT.md

## v0.1 Alpha Acceptance Status

Accepted for alpha packaging with the known Chrome manual QA limitation documented in `docs/KNOWN-ISSUES.md`.

## Completed

- MV3 manifest and Side Panel scaffold.
- Hermes Gateway REST adapter and minimal dashboard WebSocket adapter.
- Browser Context Protocol v1, restricted page blocking, redaction, timeout fallback, and safe receipts.
- Side Panel workspace with settings drawer, diagnostics drawer, runtime selectors, agent modes, conversation controls, spinner, and keyboard send shortcut.
- Edge and Brave real-browser smoke QA through temporary profiles.
- Codex/OpenCode agent, prompt, and local workflow files.
- Release package zip generation.

## Blocked or deferred

- Chrome UI manual QA remains manual because Chrome blocks command-line unpacked extension loading.
- Playwright E2E is deferred until a test dependency and browser-extension harness are approved.
- v0.1 screenshots are generated by `npm run qa:manual:browsers`; keep them refreshed when UI changes.
- Browser action adapter is intentionally deferred to Phase 2+.
